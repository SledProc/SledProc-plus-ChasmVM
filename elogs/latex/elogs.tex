\shead{Summary}

\vspace*{32pt}

This document provides a detailed guide for accessing and using the \eLogs{} electronic record-keeping system, including account setup, PIN and signature creation, 
and making entries in the \empht{Oil Record Book} for 
machinery space operations -- i.e., the \empht{Machinery Space} module.

\vspace*{6pt}

\begin{itemize}[itemsep=13pt, leftmargin=21pt, labelsep=13pt, 
label=\cbull{}]

\item{} User accounts and access methods: Two test user accounts are created with passwords, and \eLogs{} can be accessed via the \textbf{UAT RD} Web page or directly through site-specific URLs, preferably using a Chrome browser. Login requires NSE credentials. 

\item{} Initial PIN and signature setup: Upon first login, users must reset or create a PIN and save their signature to avoid repeated signing for each record update. This is done via 
\qce{Account Settings}, with instructions for both new and older accounts. 

\item{} Saving and using signature: After creating the signature, users must save it to avoid signing repeatedly. When submitting records, users enter their PIN to apply the saved signature. 

\item{} \eLogs{} dashboard and module navigation: The document shows the MARPOL Books dashboard and guides users to select the \empht{Oil Record Book Part I} for machinery space operations to make log entries. 

\item{} Creating daily log entries: Users click the \CreatePlus{} button to enter daily logs, ensuring all mandatory fields (underlined in red) are completed for submission. 

\item{} Entry details and time format: Entries require selecting record date and category, with times entered in military format using GMT and local time. Optional tank details can be specified regarding ballasting. 

\item{} Viewing vessel status: Users can view the vessel's last known operational or engine status from the entry screen, useful for rigs or offshore vessels. 

\item{} Categories for record entries: Various categories are available for specific record types including dirty ballast discharge, oil residues, bilge water discharge, oil filtering equipment condition, accidental oil discharges, bunkering, and general remarks. Location details are required for some entries. 

\item{} Attachments and record submission: Users can upload attachments in several file formats, save drafts, and enter officer details and signature PIN (necessary to submit records). Drafts can be deleted before final submission.  

\end{itemize}

\vspace{3em}
\sshead{.55\textwidth}{Attachments and signature}

\vspace{2em}

\item{}  For all \textbf{Categories}: to \textbf{add attachments}, click the 
\empht{browse to upload} hyperlink located in the
\empht{Attachments} section and select the appropriate file. File types that can be attached
include \bfs{PDF}, \bfs{DOCX}, \bfs{XLSX}, \bfs{PNG}, \bfs{JPG}, \bfs{GIF}, and \bfs{BMP}.

%\vspace*{14pt}

\item{}  \textbf{Optional}. To save the record book entry as a draft 
rather than submitting it for approval, in the \empht{Preview Record Book Entry} 
section, click the \empht{Save as Draft} button.  Once a record is saved as a 
draft, the \empht{Delete} button will appear in the
\empht{Preview Record Book Entry} section.

\vspace*{25pt}

\hspace*{-54pt}\includegraphics[scale=1,
 trim=0 0 0 70pt, clip]{pics/pics/ORB-A.png}

\vspace*{14pt}

\item{}  In the \empht{Sign} section, enter the 
\empht{Officer-In-Charge}, \empht{Rank}, and signature.

\item{}  From the \empht{Preview Record Book Entry} section, click the 
\empht{Submit} button. An \empht{Enter Your PIN Number} dialog displays.

\item{}  Enter the appropriate \textbf{Pin Number} and then click \qce{Ok}.

\end{enumerate}
