\p{\lPacTk{} is a customizable \PDF{} viewer and a class-library 
for mid-stream publishing workflows}

\p{Use cases include:}


\begin{description}

\item[\textbullet{}Navigation Handles for Finding Index Terms:] \hspace*{-16pt} After a 
user selects an index entry, buttons will appear 
in the margins.
These buttons will allow users to scroll between the pages 
where the index term appears, without needing to go back to the 
index itself each time to find the next page with a paragraph 
that matches the index entry (Figure~\Atref{fig:f1}).

\item[\textbullet{}Meta-Index for Side-by-Side Reading of 
Multiple Books:]  \hspace*{-16pt}  This allows indexes from 
multiple books to be pooled into a single searchable database.  Then, 
users who are reading one book from the publisher 
can select a word or phrase --- the 
\PDF{} viewer will then find matching pages from other books 
by the publisher and display them in a new 
window on the same screen so they could be 
read side-by-side (Figure~\Atref{fig:f2}).

\item[\textbullet{}Compiling Indexes:] \hspace*{-16pt}  The \PacTk{} \PDF{} viewer 
has special windows for indexing tasks.  For example, after 
compiling a list of index entries, authors or production editors 
could instruct the \PDF{} viewer to work through these index 
entries to find the matching words or phrases within the 
manuscript.  The \PDF{} viewer would then insert a button next 
to each matching paragraph that could be clicked to 
automatically add the current page number or Para ID to the index. 
Another example is that 
when building an index for a second edition, 
this matching process would be performed within both books, 
allowing authors and production editors to compare the results 
side-by-side (Figure~\Atref{fig:f3}).

\vspace{5pt}

Typically, if a paragraph was referenced in the 
index for the first edition, and a similar or identical 
paragraph is preserved in the second edition, the author 
will likely want the corresponding Para ID to be 
included in the second edition's index as well.  
For this reason, examining the two editions 
side-by-side can speed up the index process, allowing 
the author or production editor to conclude quickly that a 
second-edition paragraph matches --- and hit the \q{yes} 
button to confirm, so that the locator (either as a Para ID 
or as a page number) will be added to the index.

\item[\textbullet{}Multimedia Plugins:] \hspace*{-16pt}  Another 
feature of \PacTk{}'s \PDF{} viewer is the option 
to embed windows showing different kinds of multimedia content 
that can enhance or accompany scientific publications.  
These supplemental materials might include videos, 
digital maps, computer simulations, 
\ThreeD{}/panoramic photography, and other kinds 
of \ThreeD{} graphics.  A \PDF{} document 
that contains conventional \TwoD{} graphics --- for 
example, a map centered on some specific latitude/longitude 
coordinates, or a video frame, or one shot from a simulation 
--- could then be paired with a \GUI{} 
display showing a full map, video, or \ThreeD{} graphics 
from which the still image is taken.
